# TL Build Lab — Synergy Lab v3

Throne and Liberty mobile PWA with complete weapon-pair matrix, Meta Lab, one-click presets and transparent weighted synergy scoring.

QuestLog.gg is the external reference for current weapons, armor, accessories, artifacts, runes, traits, skills and community builds.

Important: 100% means the highest score within the currently evaluated candidate set. It is not an official QuestLog ranking. Item-level live-BiS calculations require current QuestLog data ingestion and should be refreshed per patch.
